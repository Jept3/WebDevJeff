# Jeffdesign101 v2.20

This release adds persistent URL routing on top of v2.19 Project Operations.

Deploy all frontend files from this package. No new SQL migration is required if the v2.18 and v2.19 migrations have already been applied.

After deployment, fully close/reopen any installed PWA so the v2.20 service worker cache activates.

See `V2.20-PERSISTENT-ROUTING.md` for route details.
