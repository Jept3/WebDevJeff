# Jeffdesign101 v2.12 — Website Workspace

## New Admin features

- **Prompt Library** navigation page.
- Create, edit, delete, search, categorize, and copy reusable website prompts.
- Employer Details now shows the complete **Website Client Intake**.
- **Copy Full Intake** generates one clean Markdown brief for clipboard use.
- Dedicated **Website Assets** section shows files the employer uploaded for the website.

## New Employer features

- **Website Project** navigation page.
- Website name field.
- 12 collapsible client-intake sections based on the Website Client Intake Checklist.
- Adaptive text areas for long answers.
- Additional Notes section.
- "What to Send Us" reference section.
- Dedicated Website Assets uploader for logos, photos, screenshots, PDFs, DOC/DOCX, SVG and related source files.
- Assets are stored in the existing private `client-files` bucket under `<client-id>/website-assets/`.

## Required database patch

Run `V2.12-WEBSITE-WORKSPACE-PATCH.sql` once in Supabase SQL Editor before using the new save features.

The patch only adds:

- `client_submissions.website_name`
- `client_submissions.website_intake` (JSONB)
- `client_submissions.website_notes`
- `website_prompts` table + RLS policies

It does **not** delete or reset existing data.
