# v2.17 Employer Website Project Viewer

- Adds a dedicated read-only Website Project Viewer for Employers.
- Separates Admin-managed production preview from editable intake.
- Project cards now provide View Website Project and Update Intake as separate actions.
- Viewer shows Admin-controlled status, staging/live link, update notes, published logo and screenshot carousel.
- If no showcase is published yet, the Employer sees a clear preview-coming-soon state.
- Intake remains editable only through Update Intake and retains Save Information.
- No database migration is required; existing v2.16 project/showcase fields are reused.
