# Jeffdesign101 v2.16 — Admin-owned Website Projects

## Employer role
Employer Website Projects are intentionally limited to client-supplied information:

- Add a Website Project
- Enter / edit Site Name
- Complete the 12-section Website Intake
- Add Additional Notes
- Save Information from inside the project page
- View Admin-managed project status
- View the Admin-published website showcase (logo, URL, screenshots, update notes)

Employer no longer controls production status, showcase publishing, website URL, logo, screenshot gallery, or project deletion.

## Admin role
From Admin → Employer Details → Website Projects → Open Admin Workspace:

- Review the full Employer intake
- Copy Full Intake
- Edit Site Name if needed
- Set status: Drafting / In Progress / Ready to Build / Completed
- Add staging/live Website URL
- Add Employer-facing progress/update notes
- Upload/replace the website logo
- Upload multiple project screenshots
- Publish/unpublish the showcase to Employer

## Database security
Run `V2.16-ADMIN-OWNED-WEBSITE-PROJECTS-PATCH.sql` once after the v2.13 and v2.14 patches.

The patch adds a database trigger that prevents Employer accounts from changing Admin-owned production/showcase columns even if they bypass the frontend. It also makes Website Project deletion Admin-only.

No existing website project or intake data is deleted.
