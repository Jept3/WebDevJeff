# v2.21 — Dual Logo Variants + Asset Preview

- Admin can upload separate logo variants for light and dark backgrounds per Website Project.
- Existing `showcase_logo_path` remains the light/primary logo for backward compatibility.
- New `showcase_logo_dark_path` stores the dark-background variant and is Admin-only.
- Employer published showcase displays the correct logo variant on its intended surface.
- Project Asset Library now automatically previews uploaded images and PDFs.
- Employer can immediately View or Delete the uploaded file from the same project intake page.
- Non-previewable files show a structured file-type card, filename, size, uploader and View action.
- Project Activity tracks either light or dark logo changes.

## Required migration
Run `V2.21-DUAL-LOGO-ASSET-PREVIEW-MIGRATION.sql` once after the v2.19/v2.20 migrations.
