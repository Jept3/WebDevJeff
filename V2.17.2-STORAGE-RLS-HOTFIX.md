# v2.17.2 Employer Project Asset Storage RLS Hotfix

Fixes Supabase `new row violates row-level security policy` errors when an Employer uploads assets from Website Project → Update Intake.

## Required database action
Run `V2.17.2-EMPLOYER-PROJECT-ASSET-RLS-PATCH.sql` once in Supabase SQL Editor.

The policy only permits authenticated Employers to access asset paths for a Website Project that belongs to their own client record. It requires `portal_permission = edit` for uploads/deletes and explicitly excludes the Admin-only `showcase` subtree.

No tables are dropped and no existing files/data are deleted.
