# Jeffdesign101 v2.18 — System Audit & Project Asset Library

## Main architectural changes

- Replaced fragmented website-file handling with a canonical `website_project_assets` metadata table.
- Every new website source file belongs to exactly one Website Project and one category.
- Canonical project source path: `<client-id>/website-projects/<project-id>/assets/<category>/<file>`.
- Categories: Logo & Brand, Photos, Content & Copy, Documents, References, Other.
- Admin and Employer read the same project asset records; permissions are enforced with RLS.
- Employer uploads only from the Website Project intake/editor. The generic Files page is now an organized library, avoiding orphan/unassigned uploads.
- Admin Website Workspace can also add source files by category.
- Existing direct project files are registered as `Other` during migration and remain in Storage.

## Storage/security cleanup

- Replaces v2.17.x fragmented Storage policies with one v2.18 policy set.
- Uses SECURITY DEFINER ownership helpers to avoid nested RLS ambiguity.
- Employer can upload/delete only canonical source-asset paths for an owned editable project.
- Admin can upload/manage all client files.
- Admin showcase files remain in `/showcase/` and Employer Storage SELECT now requires `showcase_published = true` for those files.
- Legacy generic files remain readable for compatibility but are no longer the recommended upload destination.

## UI/workflow cleanup

- Removed the obsolete second Admin showcase modal. The full Admin Website Workspace is the only production-control page.
- Employer Files page is now a project/category asset library rather than a competing uploader.
- Employer Overview no longer encourages unassigned file uploads; website materials are managed in Website Projects.
- Admin client detail labels older generic files as Legacy Shared Files.
- Admin Website Workspace includes the categorized source Asset Library.
- Logo preview was redesigned as a two-panel light/dark contrast proof with an Enlarge action.
- Employer published showcase uses the same modern light/dark logo proof.

## Required migration

Run `V2.18-PROJECT-ASSET-LIBRARY-MIGRATION.sql` once in Supabase SQL Editor before deploying the v2.18 frontend.

This migration does not delete existing website projects or Storage objects.
