# v2.14 — Website Project Showcase

## Admin
Open **Employers → Employer Details → Website Project → Manage Showcase**.

You can set:
- Live/staging website URL
- Employer-facing progress/update note
- Website logo
- Multiple website screenshots
- Publish/unpublish visibility

All showcase media is stored privately in `client-files` under the project's own showcase folder.

## Employer
Open **Website Projects → Open Project**. Published showcases appear above the intake form with:
- Website logo
- Website/staging link
- Project update text
- Automatic screenshot carousel
- Tap/click screenshot to enlarge
- Tap/click logo to enlarge
- White and dark background toggles for inspecting the logo
