# Jeffdesign101 v2.13 — Multi Website Projects

## What changed

Employer Website Projects is now one-to-many. An Employer can create multiple independent website projects. Each project has:

- website name
- status: Draft, In Progress, Ready for Build, Complete
- the full 12-section Website Client Intake
- additional notes
- its own private asset folder for logos, photos, screenshots and documents
- created/updated timestamps

Admin Employer Details lists every Website Project separately. Each project has a collapsible complete intake and a **Copy Full Intake** button that copies a clean Markdown brief for AI/web-production workflows.

## Upgrade steps

1. Back up the Supabase project.
2. Run `V2.13-MULTI-WEBSITE-PROJECTS-PATCH.sql` once in Supabase SQL Editor.
3. Deploy/replace the frontend files from this build.
4. If installed as a PWA, fully close and reopen the app after deployment.

The patch does not drop existing tables or records. If v2.12 has a populated single Website Project intake, it migrates that content into one row in `website_projects` when no project exists for that Employer yet.

Existing files under `<client-id>/website-assets/` are preserved and displayed as **Previous Uploads / Legacy Assets**. New project uploads are stored at `<client-id>/website-projects/<project-id>/...`.
