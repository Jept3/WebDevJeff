# v2.22 — Animated Project Carousel

## Admin Website Project Workspace
- Replaced the multi-row screenshot grid with a single production carousel.
- Auto-advances every ~4.3 seconds.
- Previous/next arrow controls.
- Mouse/touch swipe support.
- Keyboard Left/Right support.
- Slide counter and animated progress dots.
- Compact thumbnail rail.
- Remove action is available on each active carousel slide.
- Clicking a screenshot still opens the existing full-screen preview.

## Employer / Client
- Published Website Project gallery uses the same carousel component.
- Auto-play, swipe, arrows, dots, thumbnail navigation and pause/play.
- Added a Latest Website Preview carousel to the Employer Overview dashboard when a published project contains screenshots.
- Swipe gestures suppress accidental lightbox opening after a drag.

## Accessibility / mobile
- Touch-first controls.
- Keyboard navigation.
- Reduced-motion preference disables autoplay/animated transitions.
- Responsive 4:3 mobile stage and horizontally scrollable thumbnail rail.

No SQL migration is required for v2.22.
