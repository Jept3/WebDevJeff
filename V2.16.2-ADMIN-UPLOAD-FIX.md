# v2.16.2 Admin Upload Fix

- Admin Website Project logo upload now starts immediately after selecting a file.
- Admin screenshot uploads now start immediately after selection.
- Upload state, success, and exact error feedback are displayed in the Admin workspace.
- Uploaded Storage paths are persisted to `website_projects` immediately.
- Existing logo is removed only after the replacement upload and database update succeed.
- Gallery uploads roll back newly uploaded files if the project metadata update fails.
- Supports normal image MIME types plus image files identified by common extensions when a browser supplies an empty MIME type.
- No database schema change is required; the existing Admin Storage policy already permits Admin uploads to `client-files`.
